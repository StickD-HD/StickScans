    Vérifications automatiques

    Chaque série est vérifiée à son rythme : toutes les 3 h quand une sortie est attendue, toutes les 12 h sinon, toutes les 48 h si elle ne sort plus rien. Les requêtes sont espacées d'au moins 45 s, pour toutes les instances du serveur.
